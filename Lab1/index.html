Lab 1: Creating a Table and Adding Rows

Aim: Create a table, add three rows with one INSERT, and show the table.

Student: Usman Khan (2410303518) Faculty: Manish Choudhary University: Invertis University Bareilly
Task 1

Create the student table

SQL Query
CREATE TABLE student (
    roll_no INT,
    name VARCHAR(30),
    marks INT
);
Database Output
Query OK, 0 rows affected
Explanation: Creates a relation named student with roll_no (integer), name (variable character string up to 30 characters), and marks (integer).

Task 2

Insert three rows in one statement

SQL Query
INSERT INTO student (roll_no, name, marks)
VALUES
(101, 'Asha', 78),
(102, 'Rohan', 64),
(103, 'Neha', 88);
Database Output
Query OK, 3 rows affected
Explanation: Inserts three tuples in a single atomic transaction, minimizing network round-trips and ensuring batch consistency.

Task 3

Display all rows

SQL Query
SELECT * FROM student;
Database Output
+---------+-------+-------+
| roll_no | name  | marks |
+---------+-------+-------+
|     101 | Asha  |    78 |
|     102 | Rohan |    64 |
|     103 | Neha  |    88 |
+---------+-------+-------+
3 rows in set
Explanation: The asterisk (*) wildcard projects all columns from the student relation.
