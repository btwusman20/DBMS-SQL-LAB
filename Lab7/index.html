Task 1

Set up the sales table

SQL Query
CREATE TABLE sales (
    salesperson VARCHAR(20), region VARCHAR(20), amount INT
);

INSERT INTO sales VALUES
('Deepak', 'North', 12000), ('Pooja', 'South', 8500),
('Deepak', 'South', 9500), ('Lata', 'North', 11000);
Database Output
Query OK, 4 rows affected
Explanation: Creates transactional sales table recording salesperson names, regions, and revenue amounts.

Task 2

Count sales rows

SQL Query
SELECT COUNT(*) AS num_sales FROM sales;
Database Output
+-----------+
| num_sales |
+-----------+
|         4 |
+-----------+
1 row in set
Explanation: COUNT(*) tallies the total number of records present in the sales table.

Task 3

Calculate total and highest amount

SQL Query
SELECT SUM(amount) AS total FROM sales;
SELECT MAX(amount) AS highest FROM sales;
Database Output
-- SUM
+-------+
| total |
+-------+
| 41000 |
+-------+
1 row in set

-- MAX
+---------+
| highest |
+---------+
|   12000 |
+---------+
1 row in set
Explanation: SUM() computes cumulative sales (12000+8500+9500+11000=41000). MAX() identifies the maximum single sale transaction (12000).
