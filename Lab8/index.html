Task 1

Set up the shop_sale table

SQL Query

Task 2

Count sales in each region

SQL Query
SELECT region, COUNT(*) AS num_sales
FROM shop_sale GROUP BY region ORDER BY region;
Database Output
+--------+-----------+
| region | num_sales |
+--------+-----------+
| North  |         2 |
| South  |         2 |
+--------+-----------+
2 rows in set
Explanation: GROUP BY partitions data into subsets based on unique region values and counts items per group.

Task 3

Show regional totals and use HAVING

SQL Query
SELECT region, SUM(amount) AS total
FROM shop_sale GROUP BY region ORDER BY region;

SELECT region, SUM(amount) AS total
FROM shop_sale GROUP BY region
HAVING SUM(amount) > 20000 ORDER BY region;
Database Output
-- Regional totals
+--------+-------+
| region | total |
+--------+-------+
| North  | 23000 |
| South  | 18000 |
+--------+-------+
2 rows in set

-- HAVING SUM(amount) > 20000
+--------+-------+
| region | total |
+--------+-------+
| North  | 23000 |
+--------+-------+
1 row in set
Explanation: HAVING applies a predicate filter on aggregated group results after grouping, unlike WHERE which filters individual rows before grouping.
