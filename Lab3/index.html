Task 1

Set up the student table

SQL Query
CREATE TABLE student (
    roll_no INT, name VARCHAR(30), marks INT
);

INSERT INTO student VALUES
(101, 'Asha', 78), (102, 'Rohan', 64),
(103, 'Neha', 88), (104, 'Deepak', 52);
Database Output
Query OK, 4 rows affected
Explanation: Populates the student table with 4 records to evaluate filtering conditions.

Task 2

Show name and marks

SQL Query
SELECT name, marks FROM student;
Database Output

| Rohan  |    64 |
| Neha   |    88 |
| Deepak |    52 |
+--------+-------+
4 rows in set
Explanation: Projects only the name and marks attributes, omitting the roll_no column.

Task 3

Show students scoring above 60 and roll number 103

SQL Query
SELECT * FROM student WHERE marks > 60;
SELECT name FROM student WHERE roll_no = 103;
Database Output
-- First query: marks > 60
+---------+-------+-------+
| roll_no | name  | marks |
+---------+-------+-------+
|     101 | Asha  |    78 |
|     102 | Rohan |    64 |
|     103 | Neha  |    88 |
+---------+-------+-------+
3 rows in set

-- Second query: roll_no = 103
+------+
| name |
+------+
| Neha |
+------+
1 row in set
Explanation: Filters rows based on numeric comparison (> 60) and exact key equality (= 103).
