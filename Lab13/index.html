Aim: Combine two lists and find names present in both lists.

Task 1

Set up club tables

SQL Query
CREATE TABLE club_a (student_name VARCHAR(30));
INSERT INTO club_a VALUES ('Asha'), ('Rohan'), ('Neha');

CREATE TABLE club_b (student_name VARCHAR(30));
INSERT INTO club_b VALUES ('Neha'), ('Pooja'), ('Meera');
Database Output
Query OK, 3 rows inserted into each table
Explanation: Initializes two relations with student enrollments.

Task 2

Combine names once using UNION

SQL Query
SELECT student_name FROM club_a
UNION
SELECT student_name FROM club_b
ORDER BY student_name;
Database Output
+--------------+
| student_name |
+--------------+
| Asha         |
| Meera        |
| Neha         |
| Pooja        |
| Rohan        |
+--------------+
5 rows in set
Explanation: UNION merges both result sets and automatically deduplicates values ('Neha' appears only once).

Task 3

Find common names and include duplicates with UNION ALL

SQL Query
SELECT student_name FROM club_a
INTERSECT
SELECT student_name FROM club_b
ORDER BY student_name;

SELECT student_name FROM club_a
UNION ALL
SELECT student_name FROM club_b
ORDER BY student_name;
Database Output
-- INTERSECT
+--------------+
| student_name |
+--------------+
| Neha         |
+--------------+
1 row in set

-- UNION ALL
+--------------+
| student_name |
+--------------+
| Asha         |
| Meera        |
| Neha         |
| Neha         |
| Pooja        |
| Rohan        |
+--------------+
6 rows in set
Explanation: INTERSECT returns only records present in both sets. UNION ALL concatenates all rows without removing duplicates.
