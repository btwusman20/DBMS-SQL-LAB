Task 2

Titles starting with Data

SQL Query
SELECT title FROM book WHERE title LIKE 'Data%';
Database Output
+----------------------+
| title                |
+----------------------+
| Database Systems     |
| Data Structures in C |
+----------------------+
2 rows in set
Explanation: 'Data%' matches any string starting with 'Data' followed by any sequence of characters.

Task 3

Titles ending with C and second letter h

SQL Query
SELECT title FROM book WHERE title LIKE '%C';
SELECT title FROM book WHERE title LIKE '_h%';
Database Output
-- Ends with C
+----------------------+
| title                |
+----------------------+
| Data Structures in C |
+----------------------+
1 row in set

-- Second letter is h
+---------------+
| title         |
+---------------+
| Short Stories |
+---------------+
1 row in set
Explanation: '%C' matches strings terminating with capital 'C'. '_h%' matches any single first character followed immediately by 'h'.
