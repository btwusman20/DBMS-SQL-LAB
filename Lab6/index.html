Task 1

Set up the product table

SQL Query
CREATE TABLE product (
    product_name VARCHAR(30), category VARCHAR(20), price INT
);

INSERT INTO product VALUES
('Pen', 'Stationery', 15), ('Notebook', 'Stationery', 60),
('Calculator', 'Electronics', 850), ('Bag', 'Office', 500);
Database Output
Query OK, 4 rows affected
Explanation: Initializes product items with names, departments, and price tags.

Task 2

Sort products by price descending

SQL Query
SELECT product_name, price FROM product
ORDER BY price DESC;
Database Output
+--------------+-------+
| product_name | price |
+--------------+-------+
| Calculator   |   850 |
| Bag          |   500 |
| Notebook     |    60 |
| Pen          |    15 |
+--------------+-------+
4 rows in set
Explanation: ORDER BY price DESC sorts the output rows from highest price to lowest price.

Task 3

Show unique categories and top two products

SQL Query
SELECT DISTINCT category FROM product
ORDER BY category;

SELECT product_name, price FROM product
ORDER BY price DESC LIMIT 2;
Database Output
-- DISTINCT categories
+-------------+
| category    |
+-------------+
| Electronics |
| Office      |
| Stationery  |
+-------------+
3 rows in set

-- LIMIT 2 highest priced products
+--------------+-------+
| product_name | price |
+--------------+-------+
| Calculator   |   850 |
| Bag          |   500 |
+--------------+-------+
2 rows in set
Explanation: DISTINCT eliminates duplicate category values. LIMIT 2 restricts the result set to the first two records after descending sort.
