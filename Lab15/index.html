Lab 15: Indexes and Adding a Row

Aim: Create an index, read rows by city and add a customer.

Student: Usman Khan (2410303518) Faculty: Manish Choudhary University: Invertis University Bareilly
Task 1

Set up the customer table

SQL Query
CREATE TABLE customer (
    customer_id INT PRIMARY KEY,
    name VARCHAR(30) NOT NULL,
    city VARCHAR(20)
);

INSERT INTO customer VALUES
(1, 'Kiran', 'Kochi'), (2, 'Deepak', 'Delhi'),
(3, 'Lata', 'Mumbai'), (4, 'Asha', 'Delhi');
Database Output
Query OK, 4 rows affected
Explanation: Defines customer table with PRIMARY KEY and NOT NULL constraints, populated with 4 initial entries.

Task 2

Create an index and find Delhi customers

SQL Query
CREATE INDEX idx_city ON customer(city);

SELECT name FROM customer
WHERE city = 'Delhi'
ORDER BY name;
Database Output
Query OK, index created

+--------+
| name   |
+--------+
| Asha   |
| Deepak |
+--------+
2 rows in set
Explanation: CREATE INDEX builds a B-tree index on the city attribute, accelerating equality filtering queries.

Task 3

Insert a new customer and display the table

SQL Query
INSERT INTO customer (customer_id, name, city)
VALUES (5, 'Arjun', 'Pune');

SELECT * FROM customer ORDER BY customer_id;

Explanation: Inserts a new tuple into customer; the index on city is updated automatically by the RDBMS.
